# Adaptive buttons: proof of concept adds interface lag

## What

Prototype uses Jev judgments to change button behavior or placement.

## How Jev fits

User observes extra latency for a simple screen-position task; author agrees buttons were mainly a proof of concept.

## Why and impact

Suggests semantic UI decisions need enough value to justify roundtrip cost.

## Limits and reuse

Longer-term behavior adaptation is proposed, not measured. No usability study or proof of learned user patterns.
