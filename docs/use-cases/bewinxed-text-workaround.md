# Text workaround: costly short word sequences

## What

Novelty experiment forces typed decisions into text output.

## How Jev fits

Linked demonstration claims up to 20 words for $0.50; exact vocabulary/harness pending review.

## Why and impact

Useful counterexample to using decision models for native chat generation.

## Limits and reuse

Distinct from 30,000-word grouped vocabulary project. Cost is author report, not current service price or general generation benchmark. Source review: Code can assemble selected words into text, but this does not make Jev a useful generative API. Expensive sequential calls and incoherent continuations are direct counterexample to chatbot substitution.10/15item next-symbol tests are tiny; author-adjusted9/10 and compounded character probability assume more than measured.32questions limit is payload-specific, not universal API cap.
