# Bside: typed browser actions

## What

Run browser navigation using typed decisions.

## How Jev fits

The author uses Jev as the decision engine inside an Aside REPL and links reproducible benchmark material.

## Why and impact

Claims roughly 3.6x faster decisions and 21x lower cost on one Google-to-Wikipedia-to-Gotham task.

## Limits and reuse

A single route does not establish general performance. The claimed absence of invented clicks depends on the supplied action space.
