# BWMem: memory retrieval acceleration

## What

A memory package reports adding TypeSafe.

## How Jev fits

A three-way Choice gate distinguishes compatible merges, conflicting answers and different questions. Noul judgments curate memory candidates. A seven-day, 200-item rejection ledger supports inspection; generative extraction, summaries, embeddings and fallback remain separate.

## Why and impact

Author reports retrieval falling from several seconds to under one second.

## Limits and reuse

First-of-its-kind claim unverified; no workload size, recall comparison or independent timing. Source review: Jev handles fact-merge classification and candidate relevance inside a larger generative memory system. Preserve rejected candidates and contradiction history. Reported latency and retrieval gains do not establish Jev-only system cost or isolated accuracy impact.
