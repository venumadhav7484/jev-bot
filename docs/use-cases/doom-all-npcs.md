# Doom: player and enemies controlled by Jev

## What

Let Jev control both sides of a game.

## How Jev fits

The author replaces enemy action logic and optionally player decisions with Jev.

## Why and impact

Demonstrates multiple decision agents inside an existing simulation.

## Limits and reuse

Recorded host inspector confirms player/enemy choices, but automated player dies during demonstration. No controlled quality, cost or level-completion comparison. Game engine still controls movement/aiming mechanics; multiplayer remains proposed.
