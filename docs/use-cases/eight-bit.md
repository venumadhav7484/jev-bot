# Eight-bit computer with Jev judgments

## What

Replace combinational gate evaluations with semantic judgments.

## How Jev fits

The author describes 114 gates across 23 topological layers per clock, with registers, RAM and microcode in ordinary code.

## Why and impact

One addition demo reportedly required eighteen clocks and 2,052 judgments.

## Limits and reuse

Educational experiment, not an efficient computing architecture or evidence of dependable arithmetic. Media review: Reviewed28 sampled frames: 8-bit gate simulator loads program adding28+14 and halts with42, expected-output match. Debug UI shows Jev probabilities alongside reference signals and correction diagnostics. One instrumented demonstration, not reliable arithmetic across inputs; reference machinery and deterministic state remain essential, and exact gates are better served by code.
