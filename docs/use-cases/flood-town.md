# Flood simulation with limited individual knowledge

## What

Simulate how 24 characters react during a flood.

## How Jev fits

Each character receives only its observations, memories and relationships. Jev selects actions; game code resolves movement and consequences.

## Why and impact

The author describes an edited 92-second replay of 237 real calls.

## Limits and reuse

An edited replay is not a real-time performance measurement, and simulated actions do not predict human behavior.
