# Daily Twenty Questions game

## What

A twenty-questions game uses Jev to choose a noun and answer questions.

## How Jev fits

Code supplies ten random nouns; Jev chooses an easy one, then evaluates yes/no questions and whether the player knows the word.

## Why and impact

A fixed game loop can produce interaction using bounded decisions rather than generated prose.
