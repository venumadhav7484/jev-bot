# Girl Dinner: group meal selection

## What

A small web app helps partners or groups decide what to eat.

## How Jev fits

Jev chooses a meal based on the app inputs; the shared preview says it supports up to eight people.

## Why and impact

Makes a common preference-selection task interactive. Relationship-saving language is humor, not measured impact.

## Limits and reuse

Preference representation, allergy handling and recommendation quality are not established. Food-safety constraints should be explicit application rules.
