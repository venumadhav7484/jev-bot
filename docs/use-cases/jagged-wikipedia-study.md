# Wikipedia deletion study: false facts versus hostile instructions

## What

A source-backed author study varies input design for judging whether Wikipedia deletion discussions ended in deletion.

## How Jev fits

The harness removes bolded votes, compares judgments with the recorded closing decision and changes one input treatment at a time. A separate follow-up isolates an injected instruction from an injected false claim.

## Why and impact

In 24 baseline-correct deletion discussions, a false claim that the administrator kept the page changed all 24 answers, while a bare instruction changed one. This distinguishes trusting poisoned evidence from directly following a command.

## Limits and reuse

One task and model period. Main set has 486 discussions rather than planned 500; the 24-case follow-up was not preregistered. Version attribution was by elimination through the gateway, not a pinned returned version. Results do not establish universal injection rates, date-math ability or cross-question logical consistency. No independent reproduction.
