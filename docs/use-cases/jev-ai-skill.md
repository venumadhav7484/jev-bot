# Jev-AI-Skill: loop, route and Git decisions for coding assistants

## What

An open-source skill gives Claude Code, Codex and Hermes one workflow: plan and check work, choose the right help, and decide the next Git step.

## How Jev fits

Loop turns a goal into steps, runs configured checks and requires an independent review before work counts as finished, with run state saved to files. Route picks a model capability tier, an installed skill and whether to delegate. Git recommends commit, push or pull request from repository rules. Jev provides the judgments; the coding tool does the work.

## Why and impact

Keeps completion tied to checks and a separate review rather than the assistant's own claim, and blocks direct pushes to main by default.

## Limits and reuse

Author project; no measurements of cost, quality or review accuracy published. Built-in installation covers three clients only.
