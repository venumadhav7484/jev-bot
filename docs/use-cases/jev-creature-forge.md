# Creature Forge: typed traits become deterministic SVG anatomy

## What

A creative prototype builds a creature from explicit prompt facts and bounded semantic decisions.

## How Jev fits

Choice, Noul and Score questions fill an inspectable genome in stages. Code owns constraints, anatomy and rendering; per-part provenance distinguishes literal input, model inference, rules and local edits.

## Why and impact

An example of visual output without asking Jev to generate an image or SVG text. Existing genomes can render and replay without another model call.

## Limits and reuse

Finite parts and approximate geometry limit expression. Reported constraint checks on a small prompt sample are not semantic-accuracy or visual-quality measures. Live demo/media not inspected; valid typed anatomy can still represent the prompt poorly.
