# Paper Radar: filter research feeds and label your misses

## What

A daily paper feed uses Jev to judge title/abstract evidence against user interests and publish selected records.

## How Jev fits

Each interest gets a Noul and contribution type gets a Choice; code owns thresholds, feed intake, dates and publishing. Optional prose comes from a separate writer. User labels feed a calibration command.

## Why and impact

The author reports 501 papers processed in 33 seconds for $0.0196. A separate 299-paper observation found more high-probability hits for concrete interests than for broad comparative claims, suggesting question wording should be tested.

## Limits and reuse

Hit counts alone cannot establish precision or recall. The current README includes newer screening claims beyond the original post; those datasets were not independently audited here. Offline demo output uses a heuristic rather than live Jev. Missing abstract evidence or broad interests can hide relevant papers.
