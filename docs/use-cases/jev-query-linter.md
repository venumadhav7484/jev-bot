# Jev query linter: static checks plus semantic feedback

## What

A linter reviews Jev request wording and shape, combining static analysis with Jev-powered feedback.

## How Jev fits

The author provides a CLI and PHP, JavaScript and Python interfaces so developers or coding agents can inspect queries before wider use.

## Why and impact

Potentially useful for discovering malformed structures and ambiguous questions while making query iteration explicit.

## Limits and reuse

A linter judgment does not prove a query works on real inputs. Static validity, semantic criticism and measured task performance are separate. Distinct project from the earlier code-style JevLint case; effectiveness and rules require further source/evaluation review.
