# JevSpeak: judgments rendered as sentences

## What

A chat-like interface compiles typed judgments into finite sentence patterns.

## How Jev fits

Thirteen semantic questions feed an intermediate representation and deterministic language templates. Locale packs change wording; a debug view shows judgments and compiler repairs.

## Why and impact

Demonstrates communication through an application renderer without asking Jev to generate prose.

## Limits and reuse

Finite claim vocabulary limits factual answers. Confidence-based wording is not proof of calibration. The repository separates mock and API modes; neither UI fluency nor a demo establishes open-ended chat capability.
