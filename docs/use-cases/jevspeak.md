# JevSpeak: judgments rendered as sentences

## What

A chat-like interface compiles typed judgments into finite sentence patterns.

## How Jev fits

Jev answers 13 semantic questions in parallel. A deterministic grammar maps the decisions into sentences and changes language without rerunning the underlying judgments.

## Why and impact

Demonstrates communication through an application renderer without asking Jev to generate prose.

## Limits and reuse

Finite claim vocabulary limits factual answers. Confidence-based wording is not proof of calibration. The repository separates mock and API modes; neither UI fluency nor a demo establishes open-ended chat capability. Latest source review: The inspected landing page and launch post describe an authored renderer, not arbitrary native text generation. Mapping probabilities to words such as maybe or probably does not establish calibrated factual confidence. No live conversation or benchmark was independently run.
