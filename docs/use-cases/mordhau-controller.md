# Mordhau: state-driven duels and parries

## What

Jev controls a fighter in Mordhau through an Unreal Engine harness.

## How Jev fits

SDK-derived game state and action options go to Jev; actual game functions execute choices. Author reports about three decisions per second, largely limited by Wi-Fi.

## Why and impact

First duel win and successful parries reported; three-day aggregate spend about $0.21.

## Limits and reuse

Doors and walls cause pathing failures. No win-rate or cost accounting protocol; this is runtime action selection, not Jev writing an Unreal game.
