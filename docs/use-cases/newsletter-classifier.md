# Newsletter classification cost reduction

## What

A team reports replacing excessive reasoning for newsletter judgments.

## How Jev fits

Batch two nouls for new publishing work and dated funding obligations plus counterparty choice. Skip the reasoning model only when all signals are clearly negative; mid-band answers and API failures fall through to the original workflow.

## Why and impact

Author baseline: 92 production calls averaging $0.002048 each. Jev gate measured at $0.000032 and 78–266 ms on five representative emails. Printer quote scores 0.24 for new work, but counterparty classification correctly retains full review.

## Limits and reuse

Five examples do not establish false-negative safety. The 40/60/80% skip-rate savings table is hypothetical, not observed traffic savings. API failures preserve the original path, but false-negative gates can still suppress useful review. No independent ledger, accuracy evaluation or implementation reproduction.
