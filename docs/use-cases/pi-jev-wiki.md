# Pi Jev Wiki: maintain conceptual project knowledge

## What

A Pi package maintains a project wiki of concepts, decisions and invariants.

## How Jev fits

Jev judges grounding, durability, code-derivability and placement; code owns thresholds and a decision ledger. Agents consult a table of contents on demand rather than injecting the whole wiki.

## Why and impact

Useful architecture for preserving knowledge while tracking changes that invalidate old entries.

## Limits and reuse

Benefits to architecture quality and token use remain hypotheses. The README lists decision-quality evaluation and hardening as unfinished; implementation tests are not judgment validation.
