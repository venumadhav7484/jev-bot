# Spam detection: human-versus-Jev speed game

## What

Small game lets users race Jev at recognizing spam.

## How Jev fits

Host displays a message and compares response timing for bounded classification.

## Why and impact

Engaging latency demonstration.

## Limits and reuse

No held-out corpus, false-positive rate or representative spam-defense evaluation; reaction speed is not reliability. The live page measures Jev server-side API time but human display-to-tap time; these have different timing boundaries.
