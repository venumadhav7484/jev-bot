# STLL: conditional document clauses

## What

Suggest template conditions from information already entered by a user.

## How Jev fits

Jev judges whether an NDA description includes personal data; host template logic changes the proposed clause. Author explicitly retains user confirmation.

## Why and impact

Reduces redundant form questions through bounded semantic suggestions.

## Limits and reuse

Recorded example does not establish GDPR compliance or a validated confidence threshold. User confirms the suggestion; automatic legal approval is not demonstrated.
